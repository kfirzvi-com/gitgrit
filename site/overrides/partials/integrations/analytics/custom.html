{# PostHog web analytics, cookieless (Material's "custom" analytics provider, enabled by extra.analytics in mkdocs.yml). - cookieless_mode "always": nothing is stored in the browser and no cookie is set. PostHog counts visitors with a server-side hash of IP + user agent and a salt that rotates daily, so visitors can't be followed across days. No consent banner needed (see legal/cookies.md). Never call identify(). Needs "cookieless tracking" enabled in the PostHog project's Web analytics settings, or PostHog drops these events. - Production only: runs on gitgrit.dev, not staging or local mkdocs serve. before_send is a second guard and drops every event unless the hostname is still that host, so nothing is sent from localhost, 127.0.0.1, staging, or www. - Named events sit alongside autocapture (contact_clicked, app_clicked, get_started_clicked, github_clicked, demo_clicked). demo_booked fires from the Cal.com embed (partials/cal-embed.html) when a booking completes. - Pricing page (docs/pricing.md): every CTA click above also carries `plan` (free / team / business / enterprise, from data-plan), `billing_period` (monthly / annual) and `currency` (usd / eur; European time zones start on eur). Plus pricing_period_toggled {period}, pricing_currency_toggled {currency}, and pricing_section_viewed {section} once per section per page load: plans, enterprise, faq, and each FAQ question (faq:). Scroll depth and time on page come from PostHog's $pageleave; heatmaps show where people click and hover. Mailto values are stored as mailto: plus the subject, never the address. No localStorage, sessionStorage, or cookies. navigation.instant is off, so one delegated listener per full page load is enough. - EU cloud. The project key is a public, write-only browser key. - Loader stub: PostHog's official snippet (posthog.com/docs/libraries/js). #}
