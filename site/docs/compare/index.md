# Compare GitGrit

GitGrit is the engineering standards platform. Your standards live in one place as running code, and every repository is checked against them on every push, with a clear grade from A+ to F.

Other tools touch the same problem from different angles. These pages explain what each one does, who it fits best, and where GitGrit is different. We try to be fair: if another tool fits you better, the page says so.

| Compare | What the other tool is |
|---|---|
| [GitGrit vs Port](gitgrit-vs-port.md) | An internal developer portal with scorecards |
| [GitGrit vs OpsLevel](gitgrit-vs-opslevel.md) | An internal developer portal with rubrics and scorecards |
| [GitGrit vs Pandorian](gitgrit-vs-pandorian.md) | Code governance with standards written in plain English and checked by an LLM |
| [GitGrit vs Baz](gitgrit-vs-baz.md) | An AI code reviewer for pull requests |
| [GitGrit vs CodeRabbit](gitgrit-vs-coderabbit.md) | An AI code reviewer for pull requests |
